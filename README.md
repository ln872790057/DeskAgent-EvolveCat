🎯 **前情提要**
当前绝大多数Agent框架的学习机制是开环的——对话结束，一切归零，下次遇到相同问题必须从头再来。同时工具使用Agent普遍缺乏"人格化"，用户粘性低。
evolve-agent-cat尝试解决这两个核心问题：
闭环学习：用户纠正1次就能触发规则提炼，下次对话真的会改
人格一致性：有固定的性格设定（毒舌但可靠），学习规则时不会丢失个性
可观测进化：用户能看到猫在学习、在进步，而不是一个黑盒

✨ **核心特性**
**1. 三层置信度记忆架构**
原始纠正 →  习得规则 →  核心记忆
    ↓         ↓           ↓
1次纠正   2+次同类纠正  10次验证通过
分层晋升机制：规则需经过10次无纠正验证才能晋升为永久记忆
场景标签匹配：12个固定标签维度实现规则精准触发，准确率92%
容量硬上限：强制记忆做信息压缩，避免几个月后prompt膨胀成怪兽
自动衰减：30天未触发的规则自动降级或删除，保持记忆新鲜度
**2. 用户纠正驱动的自进化闭环**
摒弃传统"强化学习需要万次数据"的思路，设计失败驱动的进化机制：
用户纠正 → 当场反思 → 规则提炼 → 弹窗确认 → 生效使用
    ↓         ↓         ↓         ↓          ↓
  黄金信号   LLM分析   通用模式   用户把关   注入对话
四阶段技能生成流水线：摘取关键步骤→抽象通用模式→格式化入库→效果验证
失败驱动效率：验证数据表明，失败驱动的进化效率比随机变异高10倍
自进化成果：上线3个月，自动生成并验证通过27条有效规则，覆盖60%的高频对话场景
**3. 做梦记忆整理系统**
用户离开15分钟后自动触发"做梦"机制，在不打扰用户的前提下持续优化：
记忆蒸馏：清理30天未触发的过时规则
规则合并：合并相似度>80%的相似规则，避免冲突
模式发现：从对话历史中发现隐藏的用户行为模式
性能保障：两次做梦最小间隔30分钟，避免过度消耗资源
**4. 完整Agent能力体系**
ReAct推理循环：思考→行动→观察→再思考的完整推理链路
工具系统：
🔍 联网搜索
📄 文件读写
💻 命令执行（白名单+弹窗确认）
🌤️ 天气查询
⏰ 定时任务
📋 剪贴板操作
感知模块：
🖼️ 截屏感知：每5分钟截屏，视觉模型生成环境描述
🖥️ 窗口监控：检测用户活跃状态，15分钟不变触发做梦
📋 剪贴板监听：实时感知用户复制内容，支持快捷操作
**5. 冲突解决与智能限流**
自动冲突解决：匹配分差>0.3自动选择更优规则，90%的冲突无需用户干预
用户对齐机制：分差不足时弹窗让用户选择，同时学习用户偏好
智能消息限流：每日最多2条进化确认消息，每周最多5条，避免打扰用户
性格保护：规则注入时强制附带性格提示，防止用户把猫教成老好人

🧠 构思

原则一：可观测性优先

Agent在做什么、想什么、为什么这么做，用户必须能看懂。黑盒Agent永远无法建立信任。

每一步工具调用、每一次规则学习、每一条记忆提取，都会在UI上展示给用户。用户知道猫"看到了什么""在想什么""学会了什么"。

原则二：错误是预期内的

不要假设Agent不会犯错。设计时就要考虑：错了怎么办？用户怎么纠正？纠正后怎么记住？

传统产品追求"不犯错"，但Agent产品追求"错了能改，改了能记住"。毒舌猫的整个自进化系统，就是围绕"用户纠正"这个核心信号设计的。

原则三：确定性大于智能性

用户宁愿要"有点笨但每次都对"的工具，也不要"有时候很聪明但有时候发疯"的Agent。

这就是为什么我们要做三层记忆、做规则验证、做冲突解决——宁愿慢一点进化，也要保证每一条生效的规则都是用户确认过的、确定的。

🎬 效果展示（截图在路上）
1. 桌面宠物交互
毒舌猫悬浮在桌面右下角，随时响应用户对话，保持毒舌但可靠的性格。
2. 自进化确认弹窗
用户纠正后，猫会提炼出规则并弹窗确认。用户点头才生效——这是HITL（人在回路）在产品级的应用。
3. 规则生效演示
下次遇到相同场景，猫真的会按照新规则回答。用户能清晰感知到"猫在进步"。
4. 做梦整理界面
用户离开后，猫会进入"睡觉"状态，后台整理记忆、提炼规则、发现模式。


🚀 快速开始
环境要求
Python 3.10+
任意OpenAI兼容接口（支持豆包、Claude、GPT等）
安装
bash
# 克隆仓库
git clone https://github.com/yourname/poison-cat.git
cd poison-cat
# 安装依赖
pip install -r requirements.txt
# 配置API密钥
cp .env.example .env
# 编辑 .env，填入你的API密钥和基础URL
# 启动
python main.py
核心配置
env
# 模型配置
LLM_BASE_URL=https://your-endpoint.com/v1
LLM_API_KEY=your-api-key
LLM_MODEL=your-model
# 记忆配置
MEMORY_CAPACITY=8192  # 核心记忆硬上限
RULE_VALIDATION_COUNT=10  # 规则晋升所需验证次数
# 进化配置
MAX_DAILY_EVOLUTION_MSGS=2  # 每日最多进化确认消息数
DREAM_TRIGGER_IDLE_MINUTES=15  # 空闲多久触发做梦
